# УП.ПМ.13 — оформление игрового продукта

[Открыть материалы практики](https://olgakraven.github.io/2026-up.pm.13-rvmp/) — задание, подробная инструкция с работающим примером и список 30 предметных областей.

В карточке каждого варианта доступны исходный Unity-проект и отдельный оформленный пример для сверки после самостоятельной работы. Сайт также содержит PDF задания и методички и общий редактируемый шаблон отчёта Markdown.

Unity 6.6 (6000.6.2f1), C#, Unity UI. Исходная сцена `Main` сохранена с объектами и ссылками компонентов; оформленный пример — `Demonstration`. В `GameManager` выберите номер своего варианта. Общая модель реализует подбор, последовательность, перенос, вместимость, комплект и переключатели; тематическое оформление выполняется по индивидуальным условиям.

Проверены демонстрация в Unity Play Mode, правила всех 30 вариантов, экраны и повторный запуск. Собрана и открыта версия macOS. Просмотрены все страницы обоих PDF и сайт на широком и узком экранах. Проверки правил вариантов не означают ручное прохождение каждого варианта в отдельной сборке.

## Редактирование материалов

Единственный источник учебного текста — `content/course.json`; программный код — `unity-project/Assets/Scripts`. Подробности сборки: [Правила редактирования](docs/AUTHORING.md).

```sh
python -m pip install -r requirements.txt
python scripts/build.py --release
python scripts/check.py
```

Pages публикует точный проверенный комплект из `site/`; CI проверяет контрольные суммы, соответствие исходникам, ссылки и сохранность текста PDF. Несогласованная правка исходников останавливает публикацию.

Это исправление существующей практики в данном репозитории. Неизвестные реквизиты учебного плана сохранены незаполненными, соответствие строке годового плана не заявляется.
