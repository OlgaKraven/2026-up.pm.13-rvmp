# Редактирование и публикация

Учебный текст редактируется в `content/course.json`, код — в `unity-project/Assets/Scripts`. Поставляемый `methodist/` — тот же генератор Agent Methodist, без локальных паспортов, состояния и журналов.

Для сборки черновика используйте `python -m methodist build .`. Для PDF установлены зависимости из `requirements.txt`; нужен шрифт DejaVu, либо доступные Arial и моноширинный шрифт. Для явного выбора DejaVu задайте `METHODIST_FONT_DIR` как каталог его TTF-файлов. Не редактируйте сгенерированные HTML и PDF вручную.

После изменения заново проверьте проект в Unity, правила вариантов, происхождение снимков, все страницы PDF и сайт. Сборка черновика не подтверждает эти проверки. Выпуск новой практики через `python -m methodist build . --release --evidence ...` требует её реквизитов и актуальных независимых доказательств.

Текущее обновление существующего репозитория прошло проверку Agent Methodist и опубликовано по явному указанию владельца. Неизвестные реквизиты новой записи реестра не угадывались. Проверенная версия `site/` хранится в Git. Команды `python scripts/build.py --release` и `python scripts/check.py` проверяют её, а workflow Pages передаёт именно этот комплект, не пересобирая его после визуального просмотра.

Не публикуйте состояние, паспорта, журналы, личные пути и данные студентов. Не добавляйте баллы, учебный объём, распределение времени или перечни файлов для сдачи. После публикации сверяйте удалённый SHA и контрольные суммы всех файлов сайта.
